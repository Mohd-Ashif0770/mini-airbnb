# Airbnb Clone Take-Home Task

## Reference
https://airbnb-orpin-pi.vercel.app/

## Goal
Build a pixel-perfect clone of the reference Airbnb listing page using AI-assisted development.

The clone must match:
- layout, spacing, typography, colours, icons, and assets
- hover/scroll animations and transitions
- keyboard navigation, focus management, and accessibility

Do not directly lift-and-shift the reference site's bundled source/assets.

## Required Views

### Listing Page
Full property page matching the reference layout, spacing, typography, colours, and interactions.

### Photo Tour
Full-screen photo gallery opened from "Show all photos" or any hero image.

### Lightbox
Single-photo viewer opened from any gallery photo, with previous/next arrows and keyboard left/right navigation. Match interactions and animations.

Desktop only; mobile is not required.

## Tech Stack
- React is required and is the primary evaluation focus.
- Node/Express + MongoDB or PostgreSQL backend is optional bonus.
- No database or booking/reservation logic is required.
- If a backend is added, read-only listing data via API is sufficient.
- Deploy on Vercel or another free hosting platform.

## Architecture Diagram
Submit a high-level production-scale vacation-rental marketplace architecture covering:
- Frontend
- Backend
- Storage/Database
- Search
- Deployment

Lucid or Excalidraw is recommended. Submit as image or PDF.

## Evaluation
1. Modern AI workflow usage: coding agents, sub-agents, skills, prompts
2. Visual fidelity and behavioural parity, including animations, transitions, accessibility
3. Production architecture thinking
4. AI sub-agent configs for code quality and project structure
5. Bonus backend + database integration

Keep scope focused: a clean, complete frontend is better than an over-engineered incomplete one.

Include sub-agent/skill config files.

## Submission
- Do not push code to a public GitHub repository.
- Submit by email.
- ZIP must contain the code and architecture diagram.
- Include the sequence of prompts used for AI-assisted development.
